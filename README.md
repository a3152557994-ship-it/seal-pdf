## 核心技术能力

1. **积分图局部自适应阈值去纸张阴影灰底 (`extractTransparentSignature`)**：哪怕在暗光台灯下拍白纸签字，也能将不均匀灰色阴影彻底清零为 `Alpha = 0` 真透明通道，支持碳素黑/档案宝蓝/朱砂红墨水增强。
2. **触控板 / Apple Pencil 压感平滑手写板 (`smoothSignatureStrokes`)**：二次贝塞尔中点平滑 + 压感/速度动态笔锋粗细。
3. **圆形 / 椭圆形 / 法人方章几何排版与印泥纹理引擎**：五角星、圆弧等角切线排字、传统右起竖排四字方章与海绵印泥微孔噪点。
4. **合同多页骑缝章自动 N 等分切分 + 纯本地 PDF 1.4 合成 (`computePerforationSlices` + `buildMultiPageJpegPdf`)**：零第三方依赖离线直出多页 `.pdf`。
